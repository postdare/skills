# 批量图解

仅批量分支读取。本文件管理分工与验收，图稿格式、构图与判据均以 [SKILL.md](../SKILL.md) 为准。

## 1. 主 agent 固定目标与边界

列出本批目标 id、语义来源、允许修改的文件/帧、输出目录和展示场景。先处理共享依赖与语义疑点，再按可独立写入的文件分包；同文件的多个目标交给同一执行者。共享渲染器、集成入口、资源版本与最终汇总只有主 agent 写入。

复用已有已认可风格；缺少样板或用户要求先审时，先完成一份代表性样图，获得所需认可再展开。并发度依据实际资源与独立性选择。

**完成门槛**：每个目标恰好归属一个任务，每个任务有独立写入范围和输出目录；共享问题已解决；所需样图认可已取得。

## 2. 分派独立写入任务

每个任务收到以下完整上下文：

```text
按 <技能目录>/SKILL.md 完成以下全部目标：<id 清单>。
语义来源：<来源与精确位置>；展示场景：<桌面/移动/两者>。
只改：<文件及帧范围>；其余共享文件只读。
输出目录：<任务独有目录>；项目适配要求：<适配文档或无>。
保留未请求的语义，完成每个目标的图稿与来源对照。
中途不运行构建、检查、截图、拼图或格式化；由主 agent 在集成后统一验收。
返回目标完成数、改动路径、构图决定与未解决的语义/渲染问题；不把未执行检查写成通过。
```

执行者完成图稿后返回，主 agent 继续处理自己的集成工作；发现共享问题交主 agent 决定，执行者保持本包边界。

**完成门槛**：所有任务返回完整图稿与来源对照；目标清单没有遗漏；集成更新已落地，才能开始验证。

## 3. 主 agent 统一验证

按主技能对所有独立输出运行构建、检查、截图和拼图；使用仓库预览时按适配入口验证。主 agent 亲自检查所有目标的最新证据，分别记录几何、语义、JS 与视觉结果，不用子任务结论替代直接证据。

问题归回所属目标，说明 id、观察到的缺陷和保持不变的语义；小范围修正也必须更新受影响的证据。共享组件变更后，重新检查所有受影响目标。验收范围内有遗漏、语义阻塞或视觉问题时继续处理，不能只交通过的子集。

**完成门槛**：本批每个目标满足主技能所有验收门槛；受影响的集成回归已通过；保留提示逐条有理由。

## 4. 汇总交付

提供目标清单与完成数，各输出的预览、SVG、最新审图表和检查报告路径；逐目标列视觉结论、语义疑点与未执行项。需要用户认可的批次，以用户确认作为认可状态；技术验收通过不等同于用户已经认可。

**完成门槛**：交付证据覆盖整批目标，技术结果与用户认可状态分别说明。
